# Vukona Bright Shilenge | Portfolio

A personal portfolio website introducing Vukona Bright Shilenge, a software developer. It presents education, career goals, technical skills, selected projects, and contact information.

## Features

- Responsive layout with a mobile navigation menu
- Education and career-goal sections
- Project summaries for a clinic booking system, digital store, and career guidance recommender
- Scroll-triggered reveal effects and active navigation highlighting
- Portrait image in the hero section

## Built With

- HTML
- CSS
- Vanilla JavaScript

No package installation or build step is required.

## Run Locally

Open `index.html` directly in a browser, or start a local static server from the project directory:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.
